\# Production RAG Systems



A RAG system combines retrieval with generation. The retrieval component finds relevant information from a knowledge base.



\## Retrieval



Dense retrieval represents documents and queries as vectors. The vectors can be compared using similarity measures.



\### Chunking



Semantic chunking attempts to preserve meaningful boundaries. A chunk should ideally contain a coherent piece of information.



\## Evaluation



Retrieval quality can be measured using recall and precision. Generation quality requires separate evaluation approaches.
